# 后台记忆、Dream 与分层召回

状态：2026-11-08本地改造与验收记录，未发布。架构入口为[技术设计](Agent架构与工程治理技术设计.md)，配置见[配置目录](配置目录.md)。最终测试证据在本文末更新；源码实现不代表生产已启用。

## 目标与采用依据

复用 MySQL 消息、Outbox、租约任务和记忆账本。普通聊天后台判断长期价值；明确保存优先排队；Dream 维护已有记忆；回答前装配少量核心偏好与相关详情。没有 Canal、Redis 消息监听、向量记忆池或 rerank。Redis 不作记忆权威存储。

调研固定版本：

- [Clawd 增量提取](https://github.com/YuuMoko/Clawd/blob/febd3bf497a7ebf95229878d17209934dadd3eee/src/services/extractMemories/extractMemories.ts)：采用成功推进、合并触发、有界执行思路；其继承主上下文的方式不照搬，本系统只提供有界来源窗口。
- [Clawd Dream](https://github.com/YuuMoko/Clawd/blob/febd3bf497a7ebf95229878d17209934dadd3eee/src/services/autoDream/autoDream.ts)：采用低频独立整理，不照搬24小时加5会话的联合门槛或本地PID锁。
- [claude-auto-dream](https://github.com/MeCKodo/claude-auto-dream/blob/9bfa94139ba9b3554c7bc191b3a3a9ae2150a035/src/extract.js)：避免截断材料后推进整个窗口，也不把达到最大模型轮数视为处理完整。
- [agent-dream](https://github.com/cyijun/agent-dream/blob/94835b0de218c7ba87049e08e8d35c6f581c143f/scripts/check-gates.js)：采用宿主调度与整理职责分开；数据库租约与版本检查代替文件锁。

上述是第三方项目自身行为的证据，不是 Claude 官方行为保证。不开启或运行这些仓库，不复制其运行环境。

## 触发与任务状态

用户消息受理事务写 observation、window 和 Outbox。窗口使用 debounce 合并连续消息，等待不超过该窗口创建后的 max-wait；最老待处理窗口到期可启动一批。后台补偿扫描覆盖模型暂缺、旧策略遗留而未入队的材料。主任务失败不自动丢弃用户原话；失败助手正文不作提取材料。

沿用 Outbox 投递、agent_memory_job 的 PENDING/RUNNING/SUCCEEDED/CANCELLED/DEAD 状态和租约心跳。一个账户同时只认领一个后台任务，模型调用不在事务内、也不在定时线程执行。失去租约的晚到结果不得发布；实际工作线程退出前不释放本实例容量。

明确保存的窗口持久标记 explicit_request，自动任务不能消费；显式任务只消费该次请求窗口，前文仅解释指代。用户说“存”“是的”时，后台必须同时引用原始用户事实和本轮指令；助手猜测不作事实来源。纯记忆请求由宿主确认“已排队”，不用先查 Skill、调用前台模型或再次确认。复合请求排队后继续正常业务流程。

新建账户 auto_extract 默认为1；迁移不修改已有0，明确关闭的设置保持。自动提取关闭但模式仍为 ON 时，用户仍能明确请求保存；READ_ONLY/OFF 不允许写入。全局 agent.memory.enabled 仍为部署入口开关。

## 提取与发布

每批计划冻结完整 processedIds、消息 ID、run ID 与内容 hash。当前批用户材料优先进入字节预算，较早上下文只解释指代。模型返回完整处理 ID 列表以及有逐字用户引用的 PROFILE/PREFERENCE/GOAL 候选；列表不完整、来源不符或输出溢出时，不推进任何窗口。

单字确认必须有原事实证据。每项只表达一件事；学校等归 PROFILE。临时要求、假设、第三方引用、助手建议、短时情绪和凭据不保存。模型语义判断仍需真实语料验收，程序校验只能证明来源对应，不能证明所有归纳都正确。

发布保留会话优先、账户其次的锁序，复查权限 epoch、来源、租约和窗口属性。通过稳定 fact key 去重、更新，并用 observation_seq 防止跨会话乱序旧结果覆盖新值。手工/明确声明不能被普通提取覆盖。较新的明确保存可更新同一事实的明确声明，并将同值自动来源升级为明确声明；手工编辑仍要求管理界面或明确ID目标。候选变更、来源依赖、窗口 DONE 和连续游标推进在同一事务完成。

批量超限或无效结果先缩小批次重试；单条仍超限会明确进入 DEAD，留下未完成窗口与错误，不假装成功。网络错误按有限重试恢复。授权撤销时仅跳过真实失效窗口，保留其他未完成材料。DEAD 在本轮记忆进度显示“未完成”，提供“重新整理”。重试使用所有者及来源校验、幂等键和新的任务代际，原任务 Trace 输入不改写；不允许重试撤权或删除前的旧材料。不无限消耗模型。

## Dream

使用相同模型配置与租约工作器。根据整理间隔及 memory_seq 变化量触发；材料较多时按分页游标继续扫描。每批只读取有限的 USER 范围记忆，不跨视频或话题范围扩大读取。

模型只提出已有记忆之间的严格重复 MERGE 或明确纠正 INVALIDATE 关系。程序复查账户全局 sequence、所有输入版本、来源和权限后，原子发布退休标记与整理进度；并发写入导致本次提案失效，之后重新调度。失败不发布半次整理结果。

当前 MERGE 的含义是保留完整目标、退休冗余条目，不生成新的综合正文，不修改目标现有版本的依赖。手动和明确保存条目不由 Dream 自动退休。过期内容在读取时过滤；不存在仅因较旧就删除事实的规则。分页材料会补充库中关键词相关的少量记忆锚点，使不同分页的相近表达能进入同次比较；仍是有界关键词候选，不宣称穷尽全库语义关系。

退休不同于用户删除：退休记录不再召回，但原始依据仍可在授权有效时用于审查；删除清除正文、撤销依赖，并阻止旧任务复活。

## 分层召回

核心资格由程序限定：USER 全局范围、无 qualifier 的 response_length、explanation_style、response_language、response_format 偏好。学校、饮食偏好和临时主题不自动常驻。核心默认最多3条、1536字节，单独预算。

相关层使用当前问题关键词、少量近期用户文本补足指代，以及当前视频和匹配话题范围。学校等有限词汇关联由确定性查询扩展处理。候选查询先排除无效来源与退休记录，再按关键词匹配数取候选；最终以范围和词匹配排序、去重、裁剪。时间只作辅助。全部装配仍受现有默认12条、6144字节及32根引用协议限制，权限校验与恢复时原始召回固定包不变。

召回不额外调用 LLM。没有相关内容时返回空，不把所有 PROFILE 都灌入上下文。短期对话继续承接异步写入前的信息。历史聊天与视频/报告详情仍由相应工具按需读取。

## Trace 与回执

前台区分记忆任务排队、召回和固定包恢复；后台区分增量提取与 Dream。展示核心/相关数量、候选与决定、处理消息范围、整理变化与失败原因。QUEUED 永远不是已保存回执。

后台私有详情带 sourceJobId。任务计划保存输入消息清单或 memoryRefs；读取详情同时检查原 run、任务归属、当前权限 epoch、每条来源及原始资源。跨会话输入被删除、过期或撤权后，旧模型请求正文拒绝读取。重新规划保留先前 Trace 来源清单，不能因为新计划变小而放行旧详情。

## 配置与迁移

MemoryPolicyProperties 的毫秒、小时、条数、字节数均启动绑定；范围与实际消费见生成目录。没有热更新。正在运行任务使用已冻结来源清单；策略版本变化必须先排空旧工作器，不能把新算法冒充旧任务结果。

发布前停止/排空旧记忆工作器，再执行 V26。迁移添加时间、显式窗口和索引/整理进度，修改新账户默认，取消旧 EXTRACT 与旧策略任务；旧 PENDING 材料由新策略补偿入队。禁止修改已执行迁移。旧单消息 EXTRACT 执行分支和独立 consolidation 启用开关已移除。

回滚应关闭自动写入、排空任务并使用支持 V26 的兼容版本。Dream 退休状态是新读语义，不能退回忽略退休状态且继续开启记忆的旧二进制。V26还扩展了agent_run的ck_run_route以允许DIRECT；一旦写入DIRECT，旧二进制可能无法反序列化Run及prepared JSON。回滚必须使用能读取DIRECT与新任务格式的兼容包，先停止新写入并排空worker；禁止只撤回CHECK或只修改route列来伪造兼容。数据库、源消息和审计不随回滚删除。

## 用户验收步骤

验收前确认账户“助手记忆”为允许使用/保存，后台整理已开启；既有关闭设置不会被迁移强行打开。以下是发布后的验收步骤，本地通过不能替代发布：

1. 普通聊天说“我是天津大学的”。后台应保存学校关联，不能擅自写成学生、专业或学历；前台不应凭空宣称已保存。
2. 说“以后回答简短些，先给结论”。后台更新稳定偏好；新会话按这些偏好回答，Trace 区分核心和相关记忆。
3. 新开会话询问“我学校附近有什么”。相关层应找到学校关联；与问题无关的饮食偏好不因存在就注入。
4. 说“请记住，以后回答详细一点”。立即确认排队，无需 Skill 或反复确认；后台完成后更新同一偏好版本，不能同时保留两个相反当前值。
5. 说“这次用一句话回答”。当前回答遵守，但不把长期详细偏好改成简短。
6. 关闭自动整理后，普通消息不写入；模式仍允许保存时，明确“记住”仍可以主动保存。
7. 删除记忆，再用新会话验证不会召回；旧任务和旧 Trace 不得绕过删除恢复内容。
8. 在隔离环境注入失败、重启及来源到期，检查进度不虚假推进、可重试、没有半次 Dream 提交或旧详情放行。

后台只依据有限材料判断记忆价值，真实小样本通过不意味着所有表达都已覆盖。需要持续补充真实表达的固定回归集；不以放宽来源校验提高表面成功率。
