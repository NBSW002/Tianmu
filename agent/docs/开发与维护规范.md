# 开发与维护规范

状态：当前规范。建立于2026-11-07；适用agent模块，随代码变更同步维护。

统一设计见[技术设计](Agent架构与工程治理技术设计.md)，实现状态见其中第16节；配置声明见[配置目录](配置目录.md)，验证步骤见[运维与验收](运维与验收手册.md)。目标架构与当前实现必须分别描述。

## 开发入口和依赖

`runtime`负责受控循环、调用和终态应用；业务规则由`application`及业务模块拥有；`runtime.spi`定义稳定能力，应用工厂/Spring装配具体实现。模型适配器只处理供应商协议，工具注册表负责工具元数据与准入。业务代码不能用Hook审批扩大授权范围。

新增能力先写任务输入、结果、证据、权限、预算、超时、取消和幂等契约，再实现模块及注册项。新增Tool/Skill不应修改AgentRuntime；需要业务完成条件时注册唯一CompletionOwner，重复taskType启动失败，保留唯一通用fallback。Owner只处理不可变事实和提案，交付由ResponseDelivery负责；不得在Owner里发送消息、写数据库或重新调用模型。

当前ReportOwner只处理已有报告回执的交付资格；完整来源和阅读覆盖仍由DeliveryService检查。一般组合目标的完成规划、操作kind注册、RunState只读视图尚未全部实现，按主设计相应批次迁移，不以新增一个接口宣布消除全部耦合。

架构约束由GovernanceArchitectureTest检查，精确例外必须写清原因、移除条件和所属批次。禁止为让测试通过放行整个业务包。实际依赖消除后同步缩减例外，防止重新引入。

## 配置变更

模块拥有强类型配置及合法范围。时间、字节、Token、条数和并发分别命名；声明默认值、实际消费点、读取时点、重启要求和恢复行为。新增运行旋钮必须进入目录，不可只增加一个从未消费的字段。不得将安全协议常量任意配置化。

修改本轮六组数值配置后执行 `python scripts/check_agent_governance.py --write`，检查生成diff，再运行无`--write`检查及相关配置绑定/消费测试。目录检查验证声明与引用，并不能证明非默认值的所有运行行为；工厂手工new必须显式传入绑定策略，不能依赖构造器@Autowired生效。

本轮是启动配置归属迁移，不提供热更新。持久策略快照为单独的语义变更：先实现兼容读取，再启用新写入，旧Run保持LEGACY_CURRENT_POLICY，实时撤权继续执行。不得把序列化当前配置到旧Run冒充历史冻结。

## 状态、事务和扩展回调

权威事实写入走既有事务/状态所有者；Context、Trace、Redis视图不得反向成为权威。保留工具调用与结果配对，不在半个批次做终态决定。所有模型/工具终态提案经过同一个完成裁决入口，再复用终态reservation和交付校验。

取消Future不表示实际worker退出；不响应中断的任务退出前持续占用容量，晚到结果不得提交。Observer仅处理允许丢失的通知；必须提交的审计、outbox、记忆入队和后台取消清理保留显式事务/生命周期调用。现有Hook同步异常隔离不等于已实现异步超时隔离。

持久WAITING恢复与任意崩溃重放不同：结果绑定后已保存RUNNING且清空continuation的交接窗口，重启仍RUNNER_LOST。禁止无幂等证明自动重放业务副作用。成功/澄清提交异常不产生自动成功重试意图；未知提交先读取权威状态。

## 文档生命周期和变更评审

所有Markdown在[文档索引](README.md)分类。当前规范有一个入口，模块说明保留局部事实，历史提案和验收保留日期/版本并注明替代入口。机器契约、SQL和Schema保留原路径，不随历史方案归档。新设计应写来源证据、采用/放弃原因、迁移顺序、行为差异、故障窗口、验收和回滚。

每个相关PR同步代码、配置目录、状态表和证据；提交前运行治理检查。修改预算计账、持久格式、状态机、授权或终态协议时进行独立设计/实现审查，关闭P0/P1后再接受。评审通过的范围必须精确，不能沿用旧结论覆盖新语义。

每两周或连续三个业务能力合入后做一次维护检查，由当期开发负责人执行并记录：依赖例外是否增长；新增硬编码运行参数；入口/模块文档是否矛盾；跳过用例是否长期无人处理；恢复和取消指标是否恶化。只针对实际变化安排重构，不按日历重写稳定模块。这里定义团队维护节奏，没有创建自动提醒或后台任务。

## 完成标准

相关测试通过，关键不变量有故障/竞争场景证据；文档与配置目录通过检查；独立审查发现已关闭或明确限定范围；未执行项列出原因和补验条件。部署验收单独记录commit、有效配置、迁移、回滚和线上观察，不把本地模拟结果等同真实模型/生产验收。
