## 已完成

- 统一 HTTP/SSE 入口：可信身份 → FAQ → 会话记忆 → 意图/问题理解（澄清、条件、改写）/情绪三路并行 → 服务端校验 → 任务组装 → Harness。2026-10-24 新增独立意图分支，服务器版本需另行部署。
- 单 Agent 循环、取消与终态仲裁、Hook/Gate/Transform、OTel Trace、文件 Outbox 与可选 Kafka 出口。
- Skill、Prompt、Tool Schema、FAQ 独立资源目录；classPath 资源修改后构建重启，尚无热更新。
- MySQL 权威记录、Redis 会话视图、MinIO/本地私有对象，以及终态事务、幂等、重启读取与越权隔离。persistent默认复用既有MinIO，报告HTML和证据JSON存入私有bucket；实际服务器联调待完成。
- business profile：现有 JWT + Redis 在线会话、用户状态与视频归属检查、实际 SQL 查询和结果访问时再次授权。
- 首个真实指标：按日期统计当前仍保留的已入库弹幕；SQL 对账与证据一致。
- 弹幕报告本地实现：统一视频/直播间的videoId、意图和目标解析，新增 `query_danmaku` / `create_danmaku_report` 与 `danmaku-analysis` Skill，提供准确统计、有限片段观察及私有HTML产物；真实数据与服务器验收待完成。见[弹幕分析报告](弹幕分析报告.md)。
- 弹幕稳定 ID、重复投递幂等、记录与计数事务、消费者异常传播。
- 开源整理：MIT、环境变量配置、贡献与安全文档、任务规格、CI 定义和免 Key Demo 冒烟；远端工作流尚待推送触发。
