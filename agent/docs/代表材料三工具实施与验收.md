# 代表材料三工具实施与验收

日期：2026-11-08。分类：模块实现与验收记录。状态：已部署但真实报告验收失败；当前代表预算不适用于验证数据，功能未验收。目标契约见[三工具设计](反馈报告向量压缩与四工具设计.md)，本文区分已实现和待验收。

## 当前执行流程

1. VIDEO被选择时，`analyze_video_content`获得授权视频证据；仅反馈任务跳过。
2. `prepare_feedback_materials`创建持久作业，共享一次评论/弹幕快照，随后来源预处理可并行。清洗、有效字符过滤和精确去重后，Embedding按版本缓存，本任务合法成员在本地联合聚类。主Agent只收到材料引用和数量。
3. `generate_feedback_report`在宿主内汇合材料和必要视频证据，代表JSON分批进入分析模型，再全局汇总最多五个主主题。宿主验证覆盖及来源数量，持久保存规范JSON，派生兼容HTML，并经既有报告回执和完成裁决交付。

视频Tool当前同步执行；与材料Tool放在同一原生批次时走安全串行退化，不宣称视频、评论、弹幕三路同时执行。来源准备并行；分析第一批建立主题目录后，其余独立批次按既有read-parallelism有界并行；全局归并存在层间屏障。

## 模块和权威事实

`FeedbackCompression`负责清洗、分组、任务内余弦星形聚类和代表选择；`FeedbackModelProjection`统一生产模型groups投影及全局/分批字节计量。每簇先分配所有来源的必需代表，所有簇满足后再分可选名额。合格候选按已知点赞、频次、中心性、稳定ID排序，另做近重复抑制。无法覆盖全部簇时明确预算失败，不静默抽样或回退全量模型。

`FeedbackPreparationService`拥有SNAPSHOT、来源、MATERIALS、REPORT_JSON持久步骤，复用claim/lease/fence、私有对象存储和预算账本。`FeedbackAnalysisService`拥有分析、综合与结果资产。新协议阻止search、original_text、originals回灌模型；全量私有成员仅用于数量和来源校验。报告统计来自成员映射，不能表述为逐条模型阅读。

`TaskAssembler`在接受Run时冻结新协议标记；协议摘要包含压缩参数、Embedding版本和维度、输入模板及余弦算法revision。封存材料和job重复校验相同身份。旧任务不因功能开关打开而升级；本次Tool/Skill/Prompt实质变化后，早期历史资源清单不再获续跑许可，部署排空旧任务，历史终态仍可读取。

## 点赞与报告读取

业务新增`feedback_reaction`，按source/item/actor唯一，真实登录用户点赞或撤赞；不读取视频赞数替代反馈赞数。快照在同一读取事务中按页批量统计，冻结后新点赞不改变该材料。未知点赞保留null；没有反应记录的已接入来源为0。评论区提供入口，弹幕具备API和快照统计，本批不增加弹幕悬浮点赞UI。

新增迁移为`deploy/site/migrations/20261108_feedback_reactions.sql`，无自动建表。结构化报告读取复用原artifact鉴权，经Run和证据定位内部job，再执行当前视频权限检查；匿名、跨账号或撤权不可读取。前端使用Vue文本插值呈现JSON，HTML保持历史兼容和下载。

## 故障和实际保证

WAITING在持久阶段完成后恢复会复用已验收结果，SQL测试覆盖两次重建repository和service后的导出、Embedding、分析计数。外部调用成功、缓存或结果尚未持久化即崩溃，仍可能发生有界重复付费；不提供跨供应商事务或exactly-once保证。普通RUNNING进程丢失继续遵守RUNNER_LOST规则。

参数初值不是质量评测结论：有效字符默认3会排除“太吵”等短反馈；相似度0.90、每簇目标2、最多60代表和32768字节有明确限制。全局最多五主主题与向量簇数不同。长文本及父语境分别按码点截取，封存原值hash和范围，模型只接收有界窗口。

- 业务隔离MySQL/Redis：15项集成测试通过，含真实用户点赞幂等/撤销、不可见视频拒绝、快照冻结后点赞不反写。

失败样本有240条有效向量表达；最近邻余弦中位数约0.651、最高约0.843。当前0.90门槛使大多数表达成为独立簇，无法同时满足逐簇来源保留与60条上限。将阈值降至0.45虽可减少簇数，抽样却出现成长、声音、镜头等不同话题混在同一簇；把整簇成员数当作该代表的主题数量会造成误导，故未在生产采用该调整。该统计为单视频校准样本，不代表全站普遍分布。

独立复核建议：向量用于有界代表选择，主题归属和数量只覆盖模型实际阅读的代表及其严格精确重复成员；其余反馈明确统计为未进入模型分析，不再把向量邻居归属当作已确认主题数量。需要新协议revision、旧材料读取兼容、来源/时间/多样性配额、未分析数量和覆盖说明，再用该样本及低重复样本做语义与权限测试。涉及报告统计口径变化，当前仍是待实施方案，未完成该功能。
