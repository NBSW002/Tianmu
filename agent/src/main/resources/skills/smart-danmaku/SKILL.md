# 作者弹幕草稿

读取已确认视频的画面证据，再用 `prepare_danmaku_draft` 准备草稿。默认给 5 条简短、不同的作者弹幕。每条播放时间点都须落在实际分析区间内，避免同一时刻堆积。

弹幕应简短自然、贴近对应时刻，避免连续提问和长句。默认使用中性表达；不得仅凭视频画面假设作者就是画面中的人，也不得编造作者的经历、感受或制作过程。仅在用户明确提供依据时使用相关第一人称事实。

任务选中评论或弹幕作为依据时，按参考资料 `feedback-driven` 分析，并为草稿绑定本次反馈主题。反馈不可用时说明原因，停止草稿交付。交付可编辑草稿，由用户在页面确认发送。

普通视频草稿不选择反馈时，不要传 `feedback_evidence_id` 或 `feedback_topic_id`；只有明确选择反馈依据时才传对应的真实证据和主题 ID。
