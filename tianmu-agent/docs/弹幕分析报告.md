# 弹幕与观众反馈报告

当前唯一执行流程：读取对应 Skill → 按冻结来源读取可选视频 → analyze_feedback → 后台完整分析 → create_feedback_report → 私有 HTML 交付。

主 Agent 不再承载原文批次、主题累计或格式修复循环。后台服务负责流式快照、有限批次的模型分类、层级汇总、作者身份区分、原文成员关系和完整覆盖校验；统计与渲染由代码完成。

COMMENT、DANMAKU 可以独立或联合选择。VIDEO 仅在被选择时读取；采样帧不能核实声音、连续动作或因果。原文、少数意见与反对意见通过 read_result 下钻核对。超量明确失败，不把抽样结果当作全量。

没有反馈也交付空报告。READY 是分析完成，只有保存回执才是报告完成。报告必须登录读取，权限绑定当前用户、视频和运行。

数量与时间范围查询保留独立的 query_danmaku，纯视频报告使用 create_video_report。原来的分页分类报告执行器、迁移开关和回退指令已经删除，旧 HTML 与持久证据仍可读取。详见[接口契约](接口契约.md)。
